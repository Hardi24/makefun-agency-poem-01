Entry for make.fun competition **agency-poem-01** — "Write the best poem about agency" ([bounty page](https://make.fun/bounty/agency-poem-01)).

`main.ts` (Node 22, standard library only) writes one fixed, deterministic
poem, "The Handover", to `/output/entry.txt` (888 characters).

The poem is about the handover of agency between a person and the agent
that acts for them: the doing can be delegated — the kettle, the inbox,
the unanswered mail — but the choosing cannot. The turn comes the night
the speaker asks the agent to choose, and discovers that what the agent
cannot do is *want*.

Run locally:

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
```
